# web_project_homeland

## De Pátria para Pátria

## Descrição do projeto

Este projeto é uma página web responsiva desenvolvida no âmbito dos Sprints 5 e 6 da TripleTen. A página apresenta a Galeria de Arte TripleTen, com histórias e imagens relacionadas às cidades natais de membros da comunidade TripleTen.

O objetivo principal do projeto foi praticar a criação de layouts responsivos com base num design do Figma, garantindo que a página seja exibida corretamente em diferentes larguras de ecrã, incluindo 1280px, 768px e 320px.

Na continuação do projeto (Sprint 6), foram adicionadas novas secções utilizando CSS Grid Layout, efeitos de hover, sombras, gradientes e melhorias avançadas de responsividade.

## Funcionalidade

A página contém:

- cabeçalho com logotipo da TripleTen Art Gallery;
- secção principal com título, subtítulo e imagem;
- secção introdutória com texto descritivo e citação;
- galeria de imagens responsiva (`photo-grid`);
- secção de lugares (`places`) com histórias e imagens de diferentes cidades;
- card personalizado com a minha cidade natal, São Tomé e Príncipe;
- botões interativos com efeitos hover;
- imagens com efeitos hover e sombras;
- layout responsivo adaptado para desktop, tablet e mobile;
- rodapé com informação de copyright e meu nome.

## Responsividade

O projeto foi desenvolvido e testado para diferentes tamanhos de ecrã:

- 1280px;
- 1024px;
- 768px;
- 544px;
- 320px;

Também foram realizados testes em tamanhos intermédios para garantir que não existam barras de rolagem horizontais nem quebras inesperadas no layout.
